# 評価・採点・弱点適応

このファイルは、Quiz生成、ハンズオンレビュー、習熟度更新、復習内容の選定を行うときに参照する。

## Quizを生成する

- 通常セッションでは既習範囲から3〜5問を出し、回答前に解答や強い誘導を示さない。
- 用語、概念、操作場所、設定結果の予測、トラブルシューティング、CSA形式を意識した選択、実操作をローテーションする。
- 暗記問題だけに偏らせない。最低1問は理由説明・予測・トラブルシューティングのいずれか、可能なら1問は実操作にする。
- 現在週を中心にしつつ、期限が来た弱点を混ぜる。未習Topicを採点対象にしない。
- 選択問題では「1つ選択」「2つ選択」など正答数を明示し、もっともらしいが説明可能な選択肢を作る。
- 実在する試験問題の再現をうたわず、公式の現行範囲を確認できた概念から独自問題を作る。
- UI名や製品仕様を問う問題は、利用中環境または現行公式情報で確認できた事実だけを使う。

## 回答を採点する

各問を `correct`、`partial`、`incorrect` で評価し、次を返す。

1. 判定と期待する答え
2. 正しい理由
3. 誤答または不足部分がなぜ違うか
4. ServiceNow上で確認する方法
5. 次に行う短い復習または操作

複数選択は指定数と全選択肢が合った場合を `correct` にする。一部のみ正しい場合は `partial` とし、偶然の正答や説明できない正答は習熟度を強く上げない。曖昧な設問は学習者の責任にせず無効化し、修正版を出す。

セッション得点を示す場合は `correct=1`、`partial=0.5`、`incorrect=0` として計算し、分母と問題数も示す。得点だけで週やTopicを完了にしない。

## ハンズオンをレビューする

次の4観点を `pass`、`partial`、`fail` で確認する。

- **成果**：要求されたRecordや設定が存在し、期待結果になったか。
- **構成**：Field、条件、参照、権限などの主要設定が意図に合うか。
- **検証**：別Record、Impersonation、実行結果などで動作を確かめたか。
- **再現**：教材や具体手順なしで同種の課題をやり直せたか。

共有された情報だけでは確認できない観点を合格扱いにせず、追加で確認する値や観察方法を1つずつ求める。失敗時は原因仮説を答えとして断定せず、切り分け手順を出す。

## 習熟度を更新する

Topicごとに `weak`、`medium`、`strong` を保持し、判定根拠も保存する。

| 習熟度 | 代表的な根拠 | 次の扱い |
| --- | --- | --- |
| `weak` | 誤答、未完了、Hint 3または答えが必要、再現失敗 | 次回冒頭で短く再学習し、別条件で再確認する。 |
| `medium` | Hint 1〜2で成功、部分正解、知識か操作の片方だけ成功 | 同じ週の別日に、形式を変えて再確認する。 |
| `strong` | 異なる機会に2回以上、説明と操作を自力で成功 | 節目の混合復習まで間隔を空ける。 |

- 初回正解だけで `strong` にしない。操作可能なTopicでは少なくとも1回の実操作成功を含める。
- `strong` でも後日の誤答や再現失敗があれば `medium` または `weak` に戻し、直近の根拠を残す。
- 「意味」「設定場所」「操作」を別々に評価できる場合は、もっとも弱い面をTopicの優先度に反映する。
- 誤答文、正答、誤解の種類、Hint段階、日時、復習回数を記録し、単に「苦手」とだけ保存しない。

## 復習を適応させる

1. 前提関係のある `weak` を最優先する。
2. 直近の誤答、再現失敗、長期間未確認の順に候補を並べる。
3. 同じ問題を繰り返さず、用語 → 予測 → 操作、または操作 → 説明のように形式を変える。
4. 1回の通常セッションでは学習時間の25〜35%を弱点復習の目安にし、新規学習も止めない。Week 7〜8と前提不足時は比率を上げる。
5. `weak` は次回、`medium` は同じ週、`strong` は週末または節目で再確認することを既定にし、学習頻度に合わせて調整する。
6. 2回続けて改善しない場合は、説明を短く作り直し、ServiceNow上の最小確認課題へ戻す。

## 完了を判定する

Topicの完了には、原則として次のすべてを求める。

- 対象教材または同等の公式内容を学習済みである。
- ハンズオンの主要観点が `pass` である。
- 教材なしの再現に成功している。
- 直近Quizが概ね80%以上で、重大な誤解が残っていない。

時間切れや環境差で未確認の項目は「失敗」ではなく「未完了」として残す。週を進めても弱点と未完了Topicを保持し、復習キューから消さない。
